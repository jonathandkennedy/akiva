# Akiva Shapiro Law, PLLC — Website

Static site for [Akiva Shapiro Law, PLLC](https://www.akivashapirolawpllc.com) — estate planning, elder law, probate, and litigation counsel in Old Bethpage, Long Island, NY.

Plain HTML/CSS/JS generated by a Python script. No framework, no database, no build toolchain.

## Deploying

The publish directory is **`site/`**. Point any static host at it:

| Host | Setting |
|---|---|
| Netlify / Cloudflare Pages | Build command: `python3 generate_site.py` · Publish directory: `site` |
| GitHub Pages | Serve from `/site` on the default branch |
| Apache / Nginx | Upload the contents of `site/` to the web root |

Redirects ship in both formats — `site/_redirects` (Netlify/Cloudflare) and `site/.htaccess` (Apache). See [DEPLOY.md](DEPLOY.md) for the full checklist.

## Before going live

Three values in the config block at the top of `generate_site.py`:

1. **`FORMSPREE_ENDPOINT`** — the contact form is inactive until this is set. The build prints a warning while it's still the placeholder.
2. **`GA4_ID`** — paste the GA4 Measurement ID to enable analytics (empty = none injected).
3. **Phone number** — `PHONE_DISPLAY` / `PHONE_TEL`. Confirm the canonical line before launch; it appears on every page and in the structured data.

## Rebuilding

```bash
python3 generate_site.py   # regenerate site/
python3 audit_links.py     # verify internal links, orphans, sitemap parity
```

## What's here

| Path | What it is |
|---|---|
| `site/` | Generated output — the deployable site (~148 pages) |
| `generate_site.py` | Generator: templates, design system, schema, redirects, sitemap |
| `audit_links.py` | Link/orphan/sitemap integrity checker |
| `articles/*.json` | 102 Q&A articles (content source) |
| `custom/*.json` | Long-form pillar pages (lemon law, Medicaid) |
| `towns.json` | Service-area page content |
| `pages.json`, `site-plan.json` | Page inventory, URL map, and 301 redirect plan |
| `local-data.json` | Business/NAP and review data used in schema |
| `assets/` | Source images |

## Notes

- Every URL from the previous WordPress site is preserved or 301-redirected (32 redirects, in `site-plan.json`).
- Structured data: `LegalService` + `Attorney` + `Person`, plus `Article`, `FAQPage`, `VideoObject`, `Service`, and `BreadcrumbList` per page type.
- Content is legal information, not legal advice; pages carry attorney-advertising disclaimers.
